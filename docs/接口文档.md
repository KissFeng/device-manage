# 📋 接口文档：光影资产——媒体设备借用管理中心

## 1. 接口规范说明

### 1.1 统一响应格式

所有接口返回统一的 JSON 格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

**响应码说明：**
- `200`: 操作成功
- `400`: 请求参数错误
- `401`: 未登录或 Token 无效
- `403`: 权限不足
- `404`: 资源不存在
- `500`: 服务器内部错误

### 1.2 认证方式

所有需要认证的接口，需要在请求头中携带 JWT Token：

```
Authorization: Bearer <Token>
```

## 2. 认证模块接口

### 2.1 用户登录

**接口地址：** `POST /auth/login`

**接口描述：** 用户登录，验证用户名和密码，返回 JWT Token

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |

**请求示例：**

```json
{
  "username": "admin",
  "password": "123456"
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": 1,
      "username": "admin",
      "realName": "管理员",
      "role": "ADMIN"
    }
  }
}
```

## 9. 状态码说明

### 9.1 设备状态（Device Status）

- `NORMAL`: 正常
- `MAINTENANCE`: 维修中
- `SCRAPPED`: 已报废

### 9.2 借用记录状态（Borrow Status）

- `PENDING`: 申请中（待审批）
- `APPROVED`: 已批准（已借出）
- `REJECTED`: 已拒绝
- `RETURNED`: 已归还

### 9.3 用户角色（User Role）

- `ADMIN`: 管理员
- `USER`: 普通用户

### 9.4 用户状态（User Status）

- `ACTIVE`: 激活
- `INACTIVE`: 禁用

## 10. 注意事项

1. **Token 有效期**：建议 Token 有效期为 24 小时，过期后需要重新登录
2. **密码加密**：后端需要对密码进行加密存储（建议使用 BCrypt）
3. **库存控制**：批准借用时需检查可用库存是否充足，归还时需增加可用库存
4. **权限验证**：所有管理员接口都需要验证用户角色是否为 ADMIN
5. **数据校验**：所有接口都需要进行参数校验，确保数据合法性
6. **异常处理**：统一处理异常情况，返回友好的错误提示
